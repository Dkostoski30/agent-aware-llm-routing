# P5.1c: E1's ablation square on compiled real pods

Added 2026-11-25, on branch `feature/phase-5`, beside card 74 (P5.1b).

Goal:
What each of the plugin's rules on top of affinity adds on real pods: the plugin (affinity, overload guard, parallel
spill, priority) against the plugin with one rule off each, in a Williams square of four files, a seed per file. The
verdict is card 73's, held to the plugin: a variant is **slower** when turning its rule off made the runs slower in every
file by more than the files' spread, so the rule helps. Affinity is not ablated: without it the plugin is close to the
default picker, which card 74 measures.

Depends on:
Card 74's load, files and decisions; card 73's tooling; P4.13d (ASUS's `LightingService` stopped before every sitting).
