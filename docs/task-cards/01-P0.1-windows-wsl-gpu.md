# P0.1: Windows driver, WSL2, machine setup

**Manual task, done by you in Windows. No Claude Code yet: the repo doesn't exist until P0.0.**

Goal:
WSL2 with Ubuntu 24.04 sees the RTX 3050, and the machine setup is locked for all later measurements.

Depends on:
nothing

Steps:
1. Install the latest NVIDIA driver for Windows (Game Ready or Studio) from nvidia.com. Do **not** install any NVIDIA driver or CUDA toolkit inside Ubuntu later.
2. Armoury Crate: power mode **Performance**, GPU mode **Standard** (if your model has the setting). Plugged in.
3. PowerShell:
   ```powershell
   wsl --update
   wsl --install -d Ubuntu-24.04
   ```
4. Copy `windows/.wslconfig` from this kit to `C:\Users\<you>\.wslconfig`.
5. PowerShell:
   ```powershell
   wsl --shutdown
   wsl -d Ubuntu-24.04 nvidia-smi
   wsl --version
   ```
6. Windows: turn off sleep while plugged in (Settings → System → Power).
7. Make sure at least 60GB is free on the SSD.

Done when (I run this myself):
`wsl -d Ubuntu-24.04 nvidia-smi` lists the RTX 3050, and in Windows `nvidia-smi` shows close to 0 MiB used on it before anything runs.

Record in:
`versions.md` → Machine: Windows build, driver version, power mode, GPU mode, `.wslconfig`, WSL version. (Fill it in after P0.0 creates the repo; note the values now.)
