# P0.4: Two vLLM replicas on one GPU

Goal:
Prove that two 0.6B replicas run side by side on the 3050 under load, and measure what they cost.

Depends on:
P0.3

Files allowed:
infra/local/vllm-pair.sh, infra/checks/concurrency_check.py, infra/checks/test_concurrency_check.py,

versions.md (Measurements P0.4)

- infra/local/vllm-pair.sh: starts two containers from config/real.yaml on ports 8001 and 8002 (same flags as vllm-run.sh), waits until both answer /health.
- infra/checks/concurrency_check.py --ports 8001 8002 --concurrency N --minutes M:
  sends chat requests concurrently to both ports for M minutes; every 30 s samples GPU memory (nvidia-smi --query-gpu=memory.used) and container RAM (docker stats --no-stream);
  prints per-port request count, error count, p50/p95 latency, peak VRAM, peak RAM per container. Exit 1 on any error.
- Unit test for the summary math (percentiles, peak) with fixed inputs.

Notes:
