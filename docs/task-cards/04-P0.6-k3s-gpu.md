# P0.6: Kubernetes with GPU

Goal:
A pod in k3s runs a CUDA workload on the RTX 3050.

Depends on:
P0.2

Files allowed:
infra/install-k3s.sh, infra/manifests/runtimeclass-nvidia.yaml,
infra/helm/device-plugin-values.yaml,
infra/checks/gpu-check-plugin.yaml, infra/checks/gpu-check-noplugin.yaml,
Makefile (add targets k3s, gpu-check), versions.md (k3s, device plugin chart)

Interfaces / outputs:
- infra/install-k3s.sh, idempotent:
  1. install k3s with a pinned INSTALL_K3S_VERSION, --write-kubeconfig-mode 644
  2. copy kubeconfig to ~/.kube/config
  3. verify the NVIDIA runtime is in k3s's containerd config
     (/var/lib/rancher/k3s/agent/etc/containerd/config.toml contains "nvidia"); fail with a clear message if not
  4. apply infra/manifests/runtimeclass-nvidia.yaml (RuntimeClass nvidia, handler nvidia)
  5. install the NVIDIA device plugin Helm chart, pinned version, runtimeClassName=nvidia, values from infra/helm/device-plugin-values.yaml
  6. print whether the node reports allocatable nvidia.com/gpu
- infra/checks/gpu-check-plugin.yaml: pod gpu-test, runtimeClassName nvidia, image nvcr.io/nvidia/k8s/cuda-sample:nbody,
  command ["nbody","-gpu","-benchmark"], limits nvidia.com/gpu: 1, restartPolicy Never
- infra/checks/gpu-check-noplugin.yaml: same pod without the resource limit, env NVIDIA_VISIBLE_DEVICES=all (ladder step 3)
- make gpu-check: applies the plugin variant if allocatable nvidia.com/gpu >= 1, otherwise the noplugin variant; waits for completion; prints logs; deletes the pod

Notes:
