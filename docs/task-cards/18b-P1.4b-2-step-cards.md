# P1.4b-2: Live step cards

Goal:
The UI's run view shows each step card as it lands over GET /runs/{run_id}/events (P1.4b-1), then the answer.

Depends on:
P1.4b-1

Files allowed:
ui/ (run route and its components), docs/task-cards/18b-P1.4b-2-step-cards.md

Interfaces / outputs:
- The run events of schemas/run-events.v1.json through the dev server's /api proxy. The UI uses the browser's
  EventSource; no new dependency. It closes the source on the end event (otherwise the browser reconnects to a
  finished run forever); a run event resets the view, so a reconnect redraws the run from its replay.
- UI components ported from docs/design-system/components: RunHeader, StepCard, Status, Answer. The step line reads
  "Step 3 · 5 expected", never "3 of 5" (README: Content). Pod and cache badges come in P2.6; the Answer/Steps tabs
  come with the step table (P2.6).
