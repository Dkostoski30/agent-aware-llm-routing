- infra/bootstrap.sh: idempotent; installs pinned versions of git, make, jq, yq, build-essential, uv, Node.js LTS (nvm), Angular CLI, Go, golangci-lint, Helm, k9s, hf CLI (huggingface_hub); prints every version at the end.

- .pre-commit-config.yaml: ruff, ruff-format, mypy (strict for new code), golangci-lint (Go), eslint + strict TypeScript (ui/, once it exists), trailing whitespace, end-of-file, check-yaml, check-json.
- Makefile targets: test (runs all tests that exist), lint (pre-commit on all files). up/down/smoke/replay/experiment exist as targets that print "not implemented yet: <task ID>" and exit 1.

Every value has a comment saying why.
- schemas/headers.v1.json: HTTP headers x-run-id (string), x-step (integer >= 1), x-expected-steps (integer >= 1), x-parallel-group (string, optional). (D1)
- schemas/trace.v1.json: one JSON line per LLM call: schema_version, run_id, task_type, step, expected_steps, parallel_group (optional), gap_before_ms, prompt_tokens, completion_tokens; measurement fields optional: ts_start, ttft_ms, duration_ms, pod. (D9, D12)

- schemas/tests/: pytest that valid examples pass and invalid ones fail.
