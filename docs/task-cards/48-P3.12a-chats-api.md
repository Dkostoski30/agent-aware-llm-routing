# P3.12a: Chats, messages, attachments

P3.12 is split in two (2026-11-09): this card is the API against a mocked runtime; P3.12b goes through the real one.

Decided 2026-11-09 with the user: a message's run gets the chat's attachments, newest first, up to `agent.max_files`, so a follow-up can use the earlier CSV. The tool list changes only on the turn a file is added. Conversation history is P4.8's (D13), and `run-request.v1` stays as it is here.

Decided while planning: no background task. The app saves an assistant row with its `run_id` as soon as the run starts, and `GET /chats/{id}` finishes any unfinished row by asking the runtime. A restarted app pod then loses nothing and there's no second writer on the SQLite file (D7).
