# P1.5: make smoke, the UI-less end-to-end check

Goal:
One command sends a task through every layer (agent -> gateway -> EPP -> vLLM, history in Redis, metrics in
Prometheus) and exits 0 only if every layer did its part.

Depends on:
P1.3b (P1.6b only for the order: the cluster is back on the real profile)

Files allowed:
infra/checks/smoke.sh (new), Makefile (smoke target), docs/task-cards/16-P1.5-smoke.md

Interfaces / outputs:
- make smoke, on the current cluster, any profile. It prints one "ok <layer>" line per check and stops at the first
  failure with "FAIL <layer>: <what was expected, what was seen>" and exit 1:
  1. pods: vllm (all replicas of the profile), gateway, EPP, redis and agent Ready
  2. agent: the calculator task "What is 7 times 8 plus 3?" with a fixed seed reaches done within a named timeout,
     and its answer contains 59
  3. gateway: the access log has one line per step of the run, with x-run-id, x-step 1..n and x-expected-steps
  4. picker: the EPP log has a pick in the run's time window
  5. redis: the run's metadata says done, and the step count matches the gateway's line count
  6. prometheus: vllm:num_requests_running has a sample for every vllm pod
- The run-id from step 2 links checks 3-5, so the check proves this one task went through every layer.

Notes:
Reuses the calls of agent_check.sh where they fit instead of copying them. Every timeout is a named constant with a
comment. No logic beyond orchestration, so no unit tests; the failure check below proves it can go red.

Done when (I run this myself):
make smoke                                     -> six "ok" lines, exit 0
kubectl scale deployment/agent --replicas=0
make smoke                                     -> "FAIL pods: ..." (agent not Ready), exit 1
kubectl scale deployment/agent --replicas=1
make smoke                                     -> exit 0 again

experiments/log.md (the smoke output)
