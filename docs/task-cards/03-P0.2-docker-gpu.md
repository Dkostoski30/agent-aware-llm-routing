```
# P0.2: Docker + NVIDIA Container Toolkit

Goal:
Containers in WSL2 can use the GPU.

Depends on:
P0.0

Files allowed:
infra/install-docker-gpu.sh, Makefile (add target docker-gpu), versions.md (Container and cluster: Docker, Toolkit)

Interfaces / outputs:
- infra/install-docker-gpu.sh, idempotent:
  1. ensure systemd is enabled in /etc/wsl.conf ([boot] systemd=true); if it had to be added, print "run wsl --shutdown and rerun" and exit 0
  2. install Docker Engine (official apt repo, pinned version), add $USER to group docker
  3. install nvidia-container-toolkit (NVIDIA apt repo, pinned version)
  4. nvidia-ctk runtime configure --runtime=docker; restart docker
  5. print docker and toolkit versions
- make docker-gpu runs the script.

Notes:
Docker Engine inside WSL, not Docker Desktop. Never install an NVIDIA driver or CUDA inside Ubuntu.

Done when (I run this myself):
make docker-gpu
docker run --rm --gpus all nvcr.io/nvidia/k8s/cuda-sample:nbody nbody -gpu -benchmark
-> output names the RTX 3050 and prints a GFLOP/s result

Record in:
versions.md, experiments/log.md (the GFLOP/s line)

```
