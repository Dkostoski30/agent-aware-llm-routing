How to read it
A hex module on the platform is one agent task. Its column is its context, the lights around it its steps, a gear a tool call.
A capsule is one LLM call, longer when it carries more context; a light going back is the reply.
The glass tank on a pod is its KV cache: one cube per block, bright while a call uses it, dim when kept for later, grey for a finished run.
Under each call in a pod's bays: amber while the pod rereads the prompt, teal while it writes the reply.
