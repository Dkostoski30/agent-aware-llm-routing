Selects, a segmented control and switches. Every choice in this app comes from a fixed list, never free text.

- **Select** (`ag-select`): scenario in the composer, target pod beside Kill pod. Options come from the backend: the scenario list, the live pod list.
- **Segmented** (`ag-segmented`): the replay pattern, `steady` or `burst` (P2.3).
- **Switch** (`ag-switch`): routing rules in the cluster panel. They show the active profile's flags and are read-only in the UI; flags change in `config/` (D11).
