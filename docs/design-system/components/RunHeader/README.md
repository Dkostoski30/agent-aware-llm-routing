The task as a heading, then where the run is: the horse, the step count, the run id, the task type, the time.

- Running: `Step 3 · 5 expected` with the horse trotting. `expected` is `x-expected-steps`, an estimate from recorded runs, so the wording never promises it.
- Finished: `Finished in 2.1 s`, horse still.
- The segmented bar has one segment per expected step: done in `accent`, running pulses, pending in `surface-3`. A run that goes past its estimate adds amber segments (`over`).
- Tabs: Answer (cards and answer) and Steps (the table); the count is the number of steps so far.
