A pod's state as a chip: a dot and a word, on a tinted ground.

- Ready (`ready`), Starting (`starting`, blue: cold start or warm-up), Draining (`draining`, amber: scale-down), Killed (`failed`).
- The word is always there; colour alone never carries the state. Starting may add elapsed time: `Starting · 1:03`.
- Chip text uses the matching `-ink` token on the `-soft` ground: at least 5.6:1 in both themes.
