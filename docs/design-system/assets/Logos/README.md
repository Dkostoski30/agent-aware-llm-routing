The Tenax horse, still, as single-ink SVGs for use outside the app: favicons, slides, the thesis document.

- `tenax-horse-on-dark.svg`: ink `#3db5ba` (`accent`, dark theme). Use on dark grounds such as `bg` dark.
- `tenax-horse-on-light.svg`: ink `#1d7a7f` (`accent`, light theme). Use on light grounds such as `bg` light.
- 14 × 12 art pixels; scale only by whole multiples of 14px wide so pixels stay square. The eye is a hole: never fill it.
- Inside the app, render `AgentUI.horse()` instead, so it animates and follows the theme.
